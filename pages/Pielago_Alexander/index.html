Where it started

My Path into Computing

My interest in computing grew from my curiosity about computers and the technology I use every day. I often wondered how websites, applications, and games were made, and how people could turn ideas into something useful through programming. That curiosity helped me decide to take Bachelor of Science in Computer Science. As a first-year student, I am still building my foundation and learning the basics of programming, computer systems, and problem-solving. Some lessons can be challenging, especially when my code does not work as expected, but I see those moments as opportunities to understand more. I want to become more comfortable writing code, solving problems, and creating projects of my own. I know I still have a lot to learn, so I plan to keep practicing, ask questions, and learn from my mistakes. My goal is to use what I learn to build helpful and meaningful technology.

What I learned

Reflection

Creating this website helped me understand how HTML and CSS work together to present information. I learned that HTML gives a page its structure, while CSS controls its appearance and layout. I also practiced organizing content into sections, using links, and making a page easier to navigate on smaller screens. I realized that building a website takes patience because small mistakes in code or layout can affect the result. This activity improved my confidence in using basic web development tools and encouraged me to keep practicing.
